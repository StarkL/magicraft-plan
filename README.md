# 🪄 《魔法工艺》(Magicraft) AI 截图识别与最高输出 Top 3 配装器

> 专为肉鸽俯视角射击游戏《魔法工艺》打造的智能配装与攻略辅助工具。纯前端单页架构，零后端依赖，双击即用！

---

## 📖 项目简介

《魔法工艺》(Magicraft) 拥有极其丰富且极具深度的法术构筑机制：多重施法、超载散射、折射、自动追踪、奥爆术与后置充能槽位等互相连锁，不同的法术摆放顺序往往决定了秒伤（DPS）是从几百还是突破数万。

本项目提供了一个集 **游戏截图智能识别**、**法术/法杖/遗物/诅咒全量数据库**、以及 **最高输出 Top 3 构筑自动求解** 于一体的现代化 Web 工具。

---

## ✨ 核心特性

### 1. 🖼️ 游戏截图识别与自适应槽位对齐
- **剪贴板极速识别**：游戏内截图后，直接在页面按下 `Ctrl+V` 或点击【粘贴截图】，即可自动读取剪贴板图片。
- **自适应背包锚点定位 (Anchor Alignment)**：针对玩家截图尺寸不一、裁剪偏差问题，内置背包皮包与扣带特征匹配，自动对齐横向槽位，杜绝坐标漂移。
- **HSV 空槽位严格过滤**：基于饱和度与明度双重判定，精准剔除空凹槽，杜绝空槽误判。
- **角标星级识别**：自动检测法术右上角金色加号像素，准确标注 `★1`、`★2 (+)`、`★3 (++)`。
- **大模型多模态深度识别 (可选)**：支持接入 Google Gemini API（默认采用稳定快速的 `gemini-3.5-flash`），进行全图多模态深度解析与战术推演。
- **支持手动一键微调**：点击识别出的法术可随时调出 105 个法术库搜索更换，支持一键切换星级。

### 2. ⚡ 最高输出 Top 3 配装自动推演
- 根据当前识别或选定的装备池（主手法杖、副手后置槽、已有法术及套装效果），自动模拟弹道连锁与魔力回转。
- 输出排名前 3 的最佳构筑方案：
  - **预估 10 秒等效秒伤 (DPS)**
  - **单轮爆发伤害与回魔续航评估**
  - **直观的法杖槽位摆放序列图（前置槽 ➔ 后置充能槽）**
  - **核心构筑机制与实战操作手法解析**

### 3. 📚 游戏全量图鉴与百科检索
- **105 种法术**：含各星级伤害、法力消耗、充能时间、穿透等完整数值词条。
- **107 根法杖**：含前置槽数、后置槽数、回魔速度、施法间隔与专属特效。
- **86 种遗物、60 种诅咒、34 种药水**：全量数据支持实时搜索、类型筛选与弹窗详情查看。

### 4. 🔒 安全轻量，纯前端架构
- **零环境依赖**：无需 Node.js、Python 或 Docker，直接用任意浏览器打开 `index.html` 即可运行。
- **隐私安全**：API 密钥仅存储于使用者本地浏览器的 `localStorage` 中，代码库与远程服务器均无任何密钥残留。

## 🚀 快速上手

### 方式 1：直接本地打开（最简单）
直接双击根目录下的 `index.html`，即可使用浏览器体验全部功能（包括本地 CV 截图识别、图鉴查阅与配装推演）。

### 方式 2：使用本地静态服务器打开（推荐，体验完整功能）
如果需要更好的本地图片加载与大模型网络请求支持，建议通过静态服务器启动：

```bash
# Python 3
python -m http.server 8080

# 或使用 Node.js http-server / serve
npx serve .
```
打开浏览器访问 `http://localhost:8080` 即可。

## 🛠️ 关于大模型识图配置（可选）

如需启用 Gemini 多模态深度识图：
1. 打开页面右上角或识别栏中的 **【Gemini 设置】**；
2. 填入您的 Google Gemini API Key（支持官方 AI Studio 申请的免费密钥）；
3. 默认推荐选用 `gemini-3.5-flash`（秒级响应、稳定度高）；
4. 点击保存后即可直接使用大模型视觉分析能力。

> **提示**：页面内置了 **【✨ 载入当前真实装备】** 快捷按钮，即使不配置任何 API Key，也能一键载入标准高阶实战装备组合进行配装模拟测试！
